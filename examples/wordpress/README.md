# WordPress shortcode

Copy `prayerzone-examples.php` to:

```text
wp-content/plugins/prayerzone-examples/prayerzone-examples.php
```

Activate the plugin, then use:

```text
[prayerzone city="paris" lang="fr" theme="auto" qibla="true"]
```

The example validates shortcode attributes and loads the versioned module once.
