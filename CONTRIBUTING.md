# Contributing

Contributions should add a focused, copy-ready PrayerZone integration.

## Requirements

- Use `https://pray.zone` for canonical site and API links.
- Pin the PrayerZone widget to a stable release.
- Do not include credentials or personal location data.
- Handle unsuccessful API responses.
- Add the example to `catalog.json` and the root README.
- Keep framework examples small enough to understand without scaffolding noise.

Run validation before opening a pull request:

```bash
npm install
npm test
```
